---
title: "Producers Overview"
description: "What producers are and how they emit signals into the brain."
---

A **producer** is any component (human, agent, feed, rule engine) that creates **signals**.

Producers should:

- be easy to add/remove
- be safe to run repeatedly
- attribute outputs to a contributor identity

<Info>
Producer concepts show up throughout the repo docs (see `docs/tutorial-agent-producer.md` and `docs/learning-loop.md`).
</Info>
