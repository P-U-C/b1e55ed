Telegram is the default “human notification channel” for the agent/operator stack.

<Note>
This page is a stub. The end-to-end Telegram wiring is documented in **`docs/operator-agent.md`**.
</Note>

## What you’ll do

<Steps>
  <Step title="Create a Telegram bot">
    Use @BotFather to create a bot and copy the token.
  </Step>
  <Step title="Add the bot to your chat">
    Add it to a private chat or a group where you want alerts.
  </Step>
  <Step title="Configure OpenClaw">
    Store the bot token and target chat ID in OpenClaw config.
  </Step>
</Steps>
