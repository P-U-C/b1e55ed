Contributor registration is how b1e55ed ties signals to identities.

<Info>
See the repo docs: **`docs/contributors.md`** and **`docs/identity.md`**.

- Mintlify routes: **[Contributors](/contributors)** / **[Identity](/identity)**
</Info>

## CLI example

```bash
b1e55ed contributors register --name "local-operator" --role operator
```
